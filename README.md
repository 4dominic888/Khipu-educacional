# KHIPU Educacional

Sistema autoalojado para gestión de información de instituciones educativas.

## 🚀 Requisitos

- Docker + Docker Compose
- Supabase CLI (`npm install -g supabase`)
- Node.js + npm

## 🔧 Setup de supabase

```bash
# Iniciar Supabase localmente
supabase start
```

Ver más información en el archivo [README.md](supabase/README.md)
